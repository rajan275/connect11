About Connect11

Connect11 is a personal media platform designed for students to communicate, share files, and collaborate in real time. It's built with modern technologies like Supabase, HTML, CSS, and JavaScript to ensure a fast and smooth experience.

Developer Information

This website was developed by Rajan Sandhu, a Tor-only social media platform created by a user using the pseudonym wamus. The site is built for privacy and anonymity, using the Tor network to ensure secure and private communication.
